# Deadline Dash

**Deadline Dash** is a 2D top-down adventure game set on the IUT campus.

You have **36 in-game hours (18 real minutes)** to find your teammates, complete two main tasks, and finish the project before the deadline.

### Features
- IUT campus exploration
- NPC dialogue and quests
- Item collection & backpack
- REP system
- Football mini-game
- Countdown timer
- Multiple endings

### Built With
- Java 21
- LibGDX 1.14.2
- Tiled
- Gradle
- JUnit
